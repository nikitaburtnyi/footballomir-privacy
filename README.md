# Политика конфиденциальности «Футболомира»

Одна страница — `index.html`. Публикуется через GitHub Pages, адрес
указывается в App Store Connect и внутри приложения (Настройки → Родителям).

Почему отдельный репозиторий: в адресе политики не должно стоять имя чужой
игры — проверяющий Apple открывает ссылку и видит, чья это страница.

Русский и английский на одной странице: адрес один, а витрина App Store
показывает его во всех странах.

Правило: меняется игра (покупки, Game Center, сбор данных) — сначала правится
эта страница, потом отправляется сборка. Дату внизу менять вместе с текстом.
